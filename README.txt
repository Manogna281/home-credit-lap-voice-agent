HOME CREDIT LAP VOICE AGENT — ASSIGNMENT PACK

Included:
1. system_prompt.txt — full copy/paste system prompt for a voice-agent platform.
2. test_matrix.csv — 16 scenarios with expected outcomes and pass criteria.
3. *_simulated.txt — four fictional test transcripts demonstrating important branches.
4. assignment_report.docx — formatted assignment report with design, rules, test matrix, and limitations.

IMPORTANT HONESTY NOTE:
The transcripts in this package are simulated examples, not real platform calls. This package does not contain genuine audio recordings or a public call-recording URL. Those can only be generated after a voice agent is deployed/tested in a platform that supports calls/recordings, then the actual recording/transcript is shared from that platform. Do not submit simulated transcripts as real call evidence. If the evaluator strictly requires a public audio recording link, that final evidence step cannot truthfully be completed without running a real test call in an external voice-agent platform.
